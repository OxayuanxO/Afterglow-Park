# 已知差距與未驗收項目

這是可互動的公園，不是「全 P0 已驗收」的版本。精確的建置識別、實測範圍與失敗紀錄見 [PERF_NOTES](PERF_NOTES.md)。硬體、風格、美術與長玩性不從 smoke 或截圖張數推論。

## P0：既有做法與剩餘差距

| 距離規格的項目 | 現況 |
|---|---|
| 12 鏡位全達宣傳圖品質 | 已做程序化 3D 枝葉、積雪、薄霧、PBR 貼圖、軟光暈、焦點及遠城；仍可辨識部分低 LOD 輪廓與重複材質。中遠景建築比近景小屋簡化，透景、生活道具與雕飾仍不如寫實 3A。並非所有近距離物件有法線、粗糙度、AO 全通道或達到規格每米 texel 密度。 |
| 全店、全光源的光暈／光池與接觸陰影 | 動態光選位上限約 3–6；固定池、烘焙 512² 暖光／近地接觸遮蔽、月光陰影（獨立簡化樹冠）、HDR bloom 與 Medium 以上可關閉的 GTAO。沒有 CSM、選多盞路燈即時投影、完整體積步進，室內仍有近似的光色穿透與環境填光。 |
| 細枝、欄杆、陰影、視點穿模 | MSAA 及樹木 4 級 dither 交接，不保證所有移動速度下不 shimmer。木橋轉角、物件周邊、家具使用膠囊近似。跨層步進與連續遊走的證據分列，沒有對每個可能視點／每段幀都做無穿模證明。 |
| 每個位置 20 m 至少可見三種 | 80 項可定位型錄、各區不同配置，密度報告是 360° 物件 anchor／尺寸／地形／碰撞遮擋代理，並非真實像素射線或連續空間證明。新增 16 處林下小景後，舊弱點仍可通行且代理有三種可見；更細的獨立格仍有弱視線。數值見 [效能紀錄](PERF_NOTES.md)。 |
| 音景完整性 | 有原創 Web Audio 音色、8 首短段公版旋律、五座預設、材質腳步、室內與石拱隧道濾波／餘響、場景事件。沒有真人對白、完整曲長與耳機長聽／循環接縫人耳驗收；聲場為合成近似。 |
| 目標筆電與雙後端 | 沒有 Iris Xe／680M／Apple M 系列或獨顯 FPS 證據，不聲稱 30／45／60 fps。軟體 WebGPU 原生交換鏈曾輸出空白；RGBA8 目標出圖、WebGPU 合成畫布與實機後端是不同驗收範圍。先用 Chromium 桌面版；`?backend=webgl&quality=low` 可避開部分瀏覽器或驅動問題。 |
| 其他瀏覽器 | Linux 軟體 Firefox／WebKit 的較大視窗原生短測逾時。另在停用渲染迴圈的低檔診斷，Firefox 成功取大道與小屋兩張，WebKit 完成啟動及手動步進但 PNG 逾時。縮小視窗的 Firefox 原生短測在啟動後中止，未取得完成幀／合成圖。以上不等同實機 Firefox 或 macOS Safari 驗收。 |
| 30 分鐘耐久（每個建置分開） | 舊版有跑滿時但導航失敗、也有畫面提交停滯。新的每 30 秒樣本附 build hash、路點、確認完成幀／距離、資源與活動斷言；以 [最新報告](RELEASE_REPORT.md) 和 JSON 為準，不將舊版或加速步進當最新版通過。很慢的軟體渲染不等於流暢。未涵蓋 Safari、Firefox、Edge 或 VRAM 洩漏。 |

## P1：已具備核心，仍未全做完

- 有單期平面池塘倒影、Medium 以上冰場倒影，Low 冰面用遠近光場近似。濕石板不是 SSR。雪粒子取樣光場、足印與冰痕有上限；沒有所有地形的融雪、SSS、高精度雪積累、形變步痕與完整使用痕跡網。
- 照片模式支援 12 鏡位及實際 PNG 匯出、DOF、曝光、色溫、凍結、AgX/ACES。2× 受最大尺寸限制，不代表每種 GPU 已測。電影是分段樣條與轉場，不是 12 段無剪接連續運鏡；景深主要供照片使用，沒做完整的移動對焦編排。
- 11 名程序化分段關節角色（含滑冰），不是逼真骨架蒙皮或蒙皮 instancing；獨處隱藏人形並關閉合成市集聲層。外圍不做完整行人／車流系統，遠景窗光不是 8 種室內視差材質。
- 手札本機保存、加亮造訪區域、淡色足跡；未訪區是低對比標記，不是連續霧遮罩。便箋與銘牌的完整可讀文字在 E 閱讀面板，非每個模型表面刻完整長文。微縮雙屋可看而不可進，和可敲門的小精靈門不同。
- 公園節奏採可重現間隔；60 秒週期樹秀及其他小事件有淡入淡出。事件的短旋律不是實錄歌者；自動時間／天氣循環有步進驗證方法，但並未在各渲染後端目視整段 36 分鐘。三分鐘窗口的路線代理只能說明該走法；有限型錄無法保證重走同一段永遠出現全新類型。
- 場景在起始生成；材質與骨架不做 KTX2／經典模型串流、完整 shader 預熱或動態卸載。軟體第一次轉向反射或新材質會慢；高解析圖片輸出同樣吃資源。

## P2：未納入完成

攀樹屋、望遠鏡、真實星表與月相、完整野生動物群、可乘雪橇／馬車、雪人建造與保存、烤棉花糖、每日種子、日期感知、自動第一人稱桌布漫遊、IndexedDB 相簿、眼睛自適應曝光，以及完整手搖風琴、飲食與餵鹿。平安夜解鎖、手持熱杯提示、留言、木雕與浮燈是輕量實作，不等於完成全部互動。

## 續作優先序

1. 先在實體顯示器／GPU 跑雙後端，包括原生 WebGPU 合成、第一次開門與反射編譯、VRAM 與長時間幀延遲；在代表性 GPU 上用相同路徑和鏡位量測。
2. 人工逐鏡處理照明重心、雪唇邊、針葉厚度、近景道具磨損與細枝抗鋸齒；以視域巡查檢驗低密度林下視角，而非再一律加燈。
3. 用多位玩家以實時步行與耳機體驗，確認空間、種植、發現節奏與安靜程度，再增加 P1/P2 裝飾與支線。
