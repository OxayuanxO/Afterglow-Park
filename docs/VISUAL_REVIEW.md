## 五個實際坐姿與入口

五個坐姿用 E 進入坐姿、取實際眼位、確認相應的混音預設，再用 Esc 返回步行。湖畔可見倒影；涼亭以柱子／枝葉圍合；祕密花園是近燈和花盆；書隅從樹隙看主樹，但前景有一處亮芯較強；平台能見欄杆與林海之上的遠燈。四張入口縮圖實際解碼，包含修正後的湖面。這些截圖並非題示概念美術或不同引擎的替代證據。

## 軟體 WebGPU 對照

[12 個中檔鏡位總覽](../screenshots/vista-webgpu-software.jpg) 由 SwiftShader 經 RGBA8 讀回呈現的實際 2D canvas 擷取，並另測非空白瀏覽器合成畫面和原生輸入迴圈。湖面、花園及空拍保留同一組可辨特徵。對照 WebGL 2 時，小屋天花與近燈池較亮；擷取路徑及燈光更新步進不同，未認證像素一致。強制原生呈現的軟體對照仍是空白，不能當作實體 GPU 或 Safari 驗收。

## 其他引擎的取景診斷

Linux Firefox 159 的低檔 384×240 視窗，停用原生渲染迴圈後，實際產生 [大道](../screenshots/render-check/compat-firefox-promenade.png) 和 [小屋](../screenshots/render-check/compat-firefox-cabin.png) 兩張 288×180 畫布 PNG。近景、樹燈及爐火未出現整面空白；有一筆深度比較紋理過濾的瀏覽器警告。[第一幀及手動步進證據](evidence/compat-firefox-first-frame.json) 不替代正常動畫迴圈。Linux WebKit 同一診斷到達就緒並完成手動步進，但首張 PNG 未在測試期限內得到。
